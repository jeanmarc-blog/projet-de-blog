# C’est quoi ?
Raccourcis pour cibler la recherche à un site en particulier : Wikipedia, Google, Amazon, Git, des images… 13K+ de raccourcis. Impossible de tous les mémoriser. Se souvenir des plus utilisés.

# Structure
Les !bangs s’écrivent ![lettre-site] à rechercher sur le site officiel https://support.brave.app/hc/fr/articles/4410152384781-Quelles-bangs-puis-je-utiliser-dans-le-moteur-de-recherche-Brave


# Exemples
Je recherche des informations sur Thomas Mann. Voici les options qui s’offrent à moi :
- Lancer une recherche « ordinaire » sur Google ou autre => Réponses multiples de différentes sources
- Dans duckduckgo ou Brave, dans la barre d’adresse, taper !w Thomas Mann => Affiche la page de l’encyclopédie qui a pour titre Thomas Mann
- Tout en restant dans le navigateur, taper !g Thomas Mann, j’obtiens une série de résultats avec l’auteur pour sujet
- Taper !i Thomas Mann, j’obtiens des images
- Taper !a Thomas Mann, je vois tous les livre disponibles chez Amazon

# Avantages
Les recherches sont plus ciblées et les résultats pertinents sont moins noyés dans l’ensemble des réponses. J’atteins directement le bon site.

# Inconvénients
Je risque de passer à côté de liens qui pourraient être intéressés, mais autres que les cibles que j’ai indiquées au navigateurs.
